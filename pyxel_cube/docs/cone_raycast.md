# 円錐レイキャストの式

座標系と記号は `cylinder_raycast.md` と同じ。
ビュー空間 (x, 上, 手前) で光線は P = q + t*e_z、t が大きいほど手前。

## 円錐の定義

軸方向成分 s = P・a の範囲は [-H, H]。頂点は s = +H、底面は s = -H。
半径は s に対して線形に減る。

```
r(s) = m (H - s),  m = R / (2H)
```

軸からの距離の2乗は |P|^2 - s^2 なので、側面の式は次になる。

```
|P|^2 - s^2 = m^2 (H - s)^2
```

## 側面の t の方程式

s = qa + t*a_z、|P|^2 = q2 + t^2、c0 = H - qa を代入する。

```
A = 1 - a_z^2 (1 + m^2)
B/2 = a_z (m^2 c0 - qa)
C = q2 - qa^2 - m^2 c0^2
A t^2 + 2 (B/2) t + C = 0
```

A は正負どちらにもなり、ほぼ 0 のときは 1 次方程式 t = -C / (2 B/2) に落とす。
この式は頂点を挟んだ反対側の円錐(s > H)も表す。
そこで各解の s を計算し、|s| <= H の解だけを残して最大の t を採る。

## 底面

平面 `s = -H` との交点は `t = (-H - qa) / a_z`。
軸からの距離の2乗 `q2 + t^2 - H^2` が R^2 以下ならヒット。
a_z がほぼ 0 のときは底面は見えない。

## 採用する交点

側面と底面のヒットのうち t が最大のものを採る。

## 法線

側面は F = |P|^2 - s^2 - m^2 (H - s)^2 の勾配。

```
n ~ P - k a,  k = s - m^2 (H - s)
```

頂点では n が 0 になるので、ノルムに下限を設けてゼロ除算を避ける。
底面の法線は -a(頂点と反対向き)。

## 陰影

明るさの計算とディザ行列は `ellipsoid_raycast.md` と同じ。
側面と底面でランプ(パレット)を分ける。

## 検証メモ

表面を密にサンプリングして投影した画素集合と比較し、
レイキャスト結果が理想シルエットの外へ出ないことを確認した。
欠けは境界の1画素以内に収まる(特に頂点付近の細い部分)。
