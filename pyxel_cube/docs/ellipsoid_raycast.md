# 長球レイキャストの式

座標系と記号は `cylinder_raycast.md` と同じ。
ビュー空間 (x, 上, 手前) で光線は P = q + t*e_z、t が大きいほど手前。

## 楕円体の式

軸方向成分 s = P・a、半長 a、半径 b として、軸対称の楕円体は次の式。

```
s^2/a^2 + (|P|^2 - s^2)/b^2 = 1
```

`k = 1/a^2 - 1/b^2` とおくと、整理して `k*s^2 + |P|^2/b^2 = 1`。

## t の方程式

s = qa + t*a_z、|P|^2 = q2 + t^2 を代入する。

```
A = k*a_z^2 + 1/b^2
B/2 = k*a_z*qa
C = k*qa^2 + q2/b^2 - 1
A t^2 + 2 (B/2) t + C = 0
```

A = 1/b^2 - a_z^2 (1/b^2 - 1/a^2) で a > b なら常に正。
判別式が 0 以上なら交差し、手前側の解 t = (-B/2 + sqrt(D)) / A を採る。
キャップは無いので、立体の判定はこれだけで完結する。

## 法線

F = k*s^2 + |P|^2/b^2 の勾配が外向き法線になる。

```
n ~ P/b^2 + k*s*a
```

ビュー空間のまま計算でき、ワールドへ戻す必要はない。

## 陰影

```
brightness = ambient + (1 - ambient) * max(0, n・L)
```

L はビュー空間で左上手前からの光。明るさを 4 色のランプに割り当て、
ランプ間は 4x4 ベイヤー配列のしきい値でディザする。

## 縫い目

交点をワールド座標へ戻し、円周角 atan2(Z, Y) が 90 度の倍数の
±0.06 rad 以内なら縫い目色にする。先端では半径が小さいので縫い目が集中する。

## 検証メモ

表面を密にサンプリングして投影した画素集合と比較し、
レイキャスト結果が理想シルエットの外へ出ないこと、欠けもないことを確認した。
