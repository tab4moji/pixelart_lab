# 先細りラグビーボールのレイキャストの式

座標系と記号は `cylinder_raycast.md` と同じ。
ビュー空間 (x, 上, 手前) で光線は P = q + t*e_z、t が大きいほど手前。

## 形状

大球(中心 c1、半径 r1)と小球(中心 c2、半径 r2)の凸包。2球の中心は軸上にある。
中心間距離を d、軸方向成分を s = P・a とする。

```
r1 = 0.85 (固定),  d = 1.5 (固定),  r2 = r1 * ratio
c2 = c1 + d
```

ratio は 1〜5 キーで 0, 1/4, 1/2, 3/4, 1 に変わる。
全体の軸方向の幅が原点中心になるよう c1 = -(r1 + d + r2)/2 + r1 とする。

## 外接円錐

2球に外接する円錐の半頂角を a とすると次の式が成り立つ。

```
sin(a) = (r1 - r2) / d
```

接点の軸方向位置と、そこでの円錐の半径は次のとおり。

```
S_BIG   = c1 + r1 sin(a),  rho1 = r1 cos(a)
S_SMALL = c2 + r2 sin(a),  rho2 = r2 cos(a)
```

円錐面の半径は s に対して線形で、傾きは m = tan(a)。
頂点の位置を使うと m = 0(ratio = 1)で発散するので、切片 b で表す。

```
r(s) = b - m s
b    = rho1 + m S_BIG
```

ratio = 1 では sin(a) = 0、m = 0、b = r1 となり、円錐面は半径 r1 の円柱になる。
ratio = 0 では r2 = 0 で、S_SMALL = c2 が円錐の頂点に一致する。

## 表面の範囲

凸包の表面は3つの部分からなる。

- 大球: s <= S_BIG の部分
- 円錐面: S_BIG <= s <= S_SMALL の部分
- 小球: s >= S_SMALL の部分(r2 = 0 のときは存在しない)

各面の方程式の解のうち、この範囲外の解は凸包の内部にあるので捨てる。

## 球面の t の方程式

軸上の中心 c、半径 r の球と光線との交点。

```
t^2 - 2 c a_z t + (q2 - 2 c qa + c^2 - r^2) = 0
t = c a_z ± sqrt((c a_z)^2 - C)
```

## 円錐面の t の方程式

軸からの距離の2乗 |P|^2 - s^2 が r(s)^2 に等しい。
e0 = b - m qa とおき、s = qa + t a_z を代入して展開する。

```
A   = 1 - a_z^2 (1 + m^2)
B/2 = a_z (m e0 - qa)
C   = q2 - qa^2 - e0^2
A t^2 + 2 (B/2) t + C = 0
```

A がほぼ 0 のときは1次方程式 t = -C / (2 B/2) に落とす。
m = 0 では `cylinder_raycast.md` の側面の式と一致する。

## 採用する交点

各面で範囲内の解のうち最大の t を求め、その中で最大のものを採る。

## 法線

球面は (P - c a) / r。円錐(円柱)面は P - k a を正規化し、k = s - m r(s)。
接点では球面と円錐面の法線が一致するので、境界で陰影が不連続にならない。

## 陰影

明るさ、ディザ、縫い目は `ellipsoid_raycast.md` と同じ。

## 検証メモ

1〜5 の各段階と既定の比率について、3つの表面を密にサンプリングして投影した画素集合と比較し、
レイキャスト結果が理想シルエットの外へ出ないことを確認した。
欠けは比率 0(点)の細い先端で4画素あったが、いずれも境界の1画素以内だった。
