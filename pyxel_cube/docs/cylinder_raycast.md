# 円柱レイキャストの式

ビュー空間は (x, 上, 手前) で、平行投影なので光線は (x, u, t) と書ける。
t が大きいほどカメラに近い。

## 記号

- a = (a_x, a_y, a_z): 円柱の軸方向(ビュー空間、単位ベクトル)
- r: 半径、L: 半長
- q = (x, u, 0)、qa = q・a、q2 = |q|^2

## 側面

光線上の点 P = q + t*e_z の軸からの距離の2乗が r^2 になる t を解く。

```
A = 1 - a_z^2
B/2 = -a_z * qa
C = q2 - qa^2 - r^2
A t^2 + 2 (B/2) t + C = 0
```

判別式が負なら交差しない。手前側の解 t = (-B/2 + sqrt(D)) / A を採り、
`|P・a| = |qa + t*a_z| <= L` のときだけ側面ヒットとする。
A がほぼ 0(軸が視線方向)のときは側面ヒットなしとする。

## キャップ

平面 `P・a = ±L` との交点は `t = (±L - qa) / a_z`。
軸からの距離の2乗 `q2 + t^2 - L^2` が r^2 以下ならヒット。
a_z がほぼ 0(軸が画面と平行)のときはキャップは見えない。

## 採用する交点

側面とキャップのヒットのうち t が最大(最も手前)のものを採る。

## 縞の色

ヒット点をワールド座標へ戻し、円周角 atan2(Z, Y) を 16 等分した
番号の偶奇で色 10/11 を決める。逆変換は投影の式の逆で、
見下ろし角の逆回転のあとに Y 軸回転の逆を適用する。

## 検証メモ

表面を密にサンプリングして投影した画素集合と比較し、
レイキャスト結果が理想シルエットの外へ出ないことを確認した。
サンプル由来の差は境界の1画素以内に収まる。
