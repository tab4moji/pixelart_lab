# 形状定義

立方体の8頂点を共有し、面セットだけを切り替える。

## cube

四角形 6 面。

## wedge (対角線切断ブロック)

平面 `x + z = 0` で立方体を切り、`x + z <= 0` 側を残す。
この平面は垂直辺(頂点 1-2 と 4-7)を通る対角平面。
残る頂点は 0,1,2,3,4,7。結果は三角柱で、面は 5 枚。

| 面 | 頂点 | 形 |
| --- | --- | --- |
| 奥 | 1,0,3,2 | 四角 |
| 左 | 0,4,7,3 | 四角 |
| 切断面 | 1,4,7,2 | 四角(法線 (1,0,1)) |
| 上 | 3,2,7 | 三角 |
| 下 | 0,1,4 | 三角 |

切断面は辺長 2 × 2√2 の長方形。

## 描画

多角形は先頭頂点を起点とする扇状三角形分割で塗る。
