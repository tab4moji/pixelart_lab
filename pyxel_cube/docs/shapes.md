# 形状定義

形状は `shapes.py` の `SHAPES` で描画関数 `draw(yaw, elev)` に対応付ける。
立方体系はポリゴン描画、円柱・ラグビーボール・円錐・先細りラグビーボールはレイキャスト描画を使う。

## cube

四角形 6 面。

## wedge (Aキー)

平面 `x + z = 0` で立方体を切り、`x + z <= 0` 側を残す。
垂直辺(頂点 1-2 と 4-7)を通る対角平面。上下面の対角線を通る。
残る頂点は 0,1,2,3,4,7。結果は縦置きの三角柱で、面は 5 枚。

## slant (Tキー)

平面 `x + y = 0` で立方体を切り、`x + y <= 0` 側を残す。
側面 z=-1 と z=+1 の対角線(1-3 と 5-7)を通り、Z 軸に平行。
残る頂点は 0,1,3,4,5,7。結果は横倒しの三角柱で、面は 5 枚。

## cylinder (Lキー)

軸がX方向の横向き円柱。半径 0.9、半長 1.2。

- 描画: 画面の各ピクセルから光線を飛ばし、解析式で交点を求める。
- シルエット: 端の楕円と側面の接線で決まり、ポリゴン近似のはみ出しがない。
- 側面: 円周方向 16 分割で色 10 と 11 を交互に割り当て、縞にする。
- キャップ: 色 12。
- 詳細な式は `cylinder_raycast.md` を参照。

過去の実装(16角柱のポリゴン近似)は、頂点の整数丸めと塗りの端処理で
理想の楕円の外側に画素が出るため廃止した。

## rugby (Rキー)

軸がX方向の横向きラグビーボール。回転楕円体(長球)。

- 寸法: 半長 a=1.35、半径 b=0.85。縦横比は約 1.59。
- カーブ: 先端の曲率半径は b^2/a = 約 0.535。実物より少し丸みがある緩いカーブ。
- 描画: レイキャスト。キャップはなく、交点は 2 次方程式の手前側の解。
- 陰影: 交点の法線と光源方向の内積をベイヤー配列ディザで 4 段階の色(1, 4, 9, 15)にする。
- 縫い目: 子午線 4 本(円周角 90 度刻み)を色 2 で描く。
- 詳細な式は `ellipsoid_raycast.md` を参照。

ビュー変換は `cylinder_model.py` の `make_view` と `to_world` を共用する。

## cone (Kキー)

軸がX方向の横向き円錐。頂点が +X 側、底面が -X 側。

- 寸法: 高さ 2H=2.4、底面半径 R=0.9。傾き m = R/(2H) = 0.375。
- 描画: レイキャスト。側面は 2 次方程式、底面は平面との交点。最も手前を採る。
- 側面の制限: 式は頂点の向こう側の円錐も解に含むので、軸方向成分 s が [-H, H] の解だけを採る。
- 陰影: 側面はランプ(1, 5, 12, 6)、底面はランプ(1, 3, 11, 7)。ベイヤー配列ディザ。
- 詳細な式は `cone_raycast.md` を参照。

ビュー変換と明るさ計算は `cylinder_model.py` と `ellipsoid_model.py` を共用する。

## taper (Eキー)

軸がX方向の横向き先細りラグビーボール。大球(-X側)と小球(+X側)、
その2球に外接する円錐台の凸包。小球の大きさは 1〜5 キーで変えられる。

- 大球: 半径 0.85 で固定。中心間距離は 1.5 で固定。
- 小球: 半径 = 0.85 x 比率。E 直後の既定は半径 0.4(比率約 0.47)。
- 比率は 1〜5 キーで 0, 1/4, 1/2, 3/4, 1 に変わる(1=点、5=大球と1:1)。
- 外接円錐: 半頂角 a は sin(a) = (0.85 - 小球半径) / 1.5。
- 描画: レイキャスト。大球・小球・円錐面との交点のうち、軸方向成分 s が表面範囲に入るものの最も手前を採る。
- 表面範囲: 大球は s <= S_BIG、小球は s >= S_SMALL、円錐面は S_BIG <= s <= S_SMALL(接点の軸位置)。
- 比率 0(点): 小球の判定を省き、円錐面だけが先端を作る。
- 比率 1(1:1): 半頂角が 0 になり、円錐面は円柱になる。そのため円錐面の式は頂点位置ではなく切片 `intercept` で表す。
- 陰影・縫い目・パレット: rugby と共通(パレット 1, 4, 9, 15、縫い目は色 2)。
- 詳細な式は `tapered_raycast.md` を参照。

全体の軸方向の幅が原点中心になるよう、2球の中心位置を比率ごとに決める。
ファイル構成は `tapered_model.py`(形状パラメータと法線)、`tapered_hit.py`(交点)、`tapered_cast.py`(描画)。
ビュー変換と陰影は `cylinder_model.py` と `ellipsoid_model.py` を共用する。

## 描画(ポリゴン)

多角形は先頭頂点を起点とする扇状三角形分割で塗る。
