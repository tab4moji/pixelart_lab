# 形状定義

形状は `shapes.py` の `SHAPES` で (頂点列, 面列, 輪郭色) に対応付ける。
立方体系は8頂点を共有し、円柱は独自の頂点列を持つ。

## cube

四角形 6 面。

## wedge (Aキー)

平面 `x + z = 0` で立方体を切り、`x + z <= 0` 側を残す。
垂直辺(頂点 1-2 と 4-7)を通る対角平面。上下面の対角線を通る。
残る頂点は 0,1,2,3,4,7。結果は縦置きの三角柱で、面は 5 枚。

## slant (Tキー)

平面 `x + y = 0` で立方体を切り、`x + y <= 0` 側を残す。
側面 z=-1 と z=+1 の対角線(1-3 と 5-7)を通り、Z 軸に平行。
残る頂点は 0,1,3,4,5,7。結果は横倒しの三角柱で、面は 5 枚。

## cylinder (Lキー)

輸がX方向の横向き円柱。半径 0.9、半長 1.2。
16 角柱で近似する(`cylinder_model.py` の `build_cylinder`)。

- 頂点: 両端の円周に各 16 個、計 32 個。
- 側面: 四角形 16 枚。色 10 と 11 を交互に割り当て縞模様にする。
- キャップ: 16 角形を両端に 2 枚。扇状三角形分割で塗る。
- 法線: 側面は周方向の中心角、キャップは ±X。
- 輪郭: 面の色で引く(白線だと分割線がうるさいため)。

`segments` は 4 以上の偶数。奇数だと縞模様が周回でつながらないため例外にする。

## 描画

多角形は先頭頂点を起点とする扇状三角形分割で塗る。
