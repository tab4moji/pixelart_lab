# 操作方法

| キー | 動作 |
| --- | --- |
| ↑ | 見下ろし角を増やす(最大90度=真上から) |
| ↓ | 見下ろし角を減らす(最小0度=真横から) |
| a t l r k e c | 小文字: その形状だけを単独で表示する |
| A T L R K E C | 大文字(Shift+キー): いま表示中の形状へ足して合成表示する |
| 1〜5 | taper が表示中のときだけ有効。小球の大きさを変える(下表) |
| Q / ESC | 終了 |

## 形状キー

| キー | 形状 |
| --- | --- |
| A | wedge(縦置き三角柱) |
| T | slant(横倒し三角柱) |
| L | cylinder(横向き円柱) |
| R | rugby(横向きラグビーボール) |
| K | cone(横向き円錐) |
| E | taper(先細りラグビーボール) |
| C | cube(立方体) |

## 単独と足し込み

- 小文字は、表示中の形状をすべて捨ててその形状だけにする。従来どおりの描画で、見た目は変わらない。
- 大文字は、表示中の形状へその形状を足す。同じ形状を複数回足しても1つのまま(重複しない)。
- 足した形状は、すべて原点に置かれて同じ向きで回転する。Zバッファで合成するので、形状同士が重なる所は手前の面が見える。
- 初期表示は cube。たとえば L を押すと cube と円柱の合成になる。
- 左下の表示は、複数のときキー文字を + でつなぐ(例 `C+L+E3`)。taper は段階の数字つき。
- 詳細は `composite.md` を参照。

## taper の 1〜5 キー

小球の半径 = 大球の半径 x 比率。大球は常に半径 0.85。

| キー | 比率 | 小球の半径 | 形 |
| --- | --- | --- | --- |
| 1 | 0 | 0 | 点(大球に接する円錐) |
| 2 | 1/4 | 約 0.21 | 細い先端 |
| 3 | 1/2 | 約 0.43 | 中間 |
| 4 | 3/4 | 約 0.64 | 太い先端 |
| 5 | 1 | 0.85 | 両端が1:1(円柱+半球2つ) |

- E を押した直後は、従来の小球半径 0.4(比率約 0.47)のまま。数字キーを押すと段階が切り替わる。
- 段階は保持される。taper を外しても、また足したときに同じ段階で表示される。
- taper が表示中でないとき、1〜5 キーは何もしない。
- 単独のときの左下の表示は、段階を押した後だけ `TAPER 3` のように段階つきになる。

## 共通

- 押し続けると1フレームごとに ELEV_STEP(1度)ずつ変化する。
- 初期角度は 30 度(ELEV_DEFAULT)、初期形状は立方体。
- 立体はY軸まわりに自動回転する(YAW_STEP=2度/フレーム)。
- 左上の `EL xx` が見下ろし角。
