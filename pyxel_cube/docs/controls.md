# 操作方法

| キー | 動作 |
| --- | --- |
| ↑ | 見下ろし角を増やす(最大90度=真上から) |
| ↓ | 見下ろし角を減らす(最小0度=真横から) |
| A | 対角線切断ブロック wedge(縦置き三角柱)に切替 |
| T | 側面の対角線切断ブロック slant(横倒し三角柱)に切替 |
| L | 横向き円柱 cylinder に切替 |
| R | 横向きラグビーボール rugby に切替 |
| K | 横向き円錐 cone に切替 |
| E | 先細りラグビーボール taper に切替 |
| 1〜5 | taper のときだけ有効。小球の大きさを変える(下表) |
| C | 通常の立方体に切替 |
| Q / ESC | 終了 |

## taper の 1〜5 キー

小球の半径 = 大球の半径 x 比率。大球は常に半径 0.85。

| キー | 比率 | 小球の半径 | 形 |
| --- | --- | --- | --- |
| 1 | 0 | 0 | 点(大球に接する円錐) |
| 2 | 1/4 | 約 0.21 | 細い先端 |
| 3 | 1/2 | 約 0.43 | 中間 |
| 4 | 3/4 | 約 0.64 | 太い先端 |
| 5 | 1 | 0.85 | 両端が1:1(円柱+半球2つ) |

- E を押した直後は、従来の小球半径 0.4(比率約 0.47)のまま。数字キーを押すと段階が切り替わる。
- 他の形状へ切り替えても段階は保持され、E に戻ると同じ段階で表示される。
- 他の形状では 1〜5 キーは何もしない。
- 左下の表示は段階を押した後だけ `TAPER 3` のように段階つきになる。

## 共通

- 押し続けると1フレームごとに ELEV_STEP(1度)ずつ変化する。
- 初期角度は 30 度(ELEV_DEFAULT)、初期形状は立方体。
- 立体はY軸まわりに自動回転する(YAW_STEP=2度/フレーム)。
- 左上の `EL xx` が見下ろし角、左下が現在の形状名。
