# 操作方法

| キー | 動作 |
| --- | --- |
| ↑ | 見下ろし角を増やす(最大90度=真上から) |
| ↓ | 見下ろし角を減らす(最小0度=真横から) |
| A | 対角線切断ブロック(三角柱)に切替 |
| C | 通常の立方体に切替 |
| Q / ESC | 終了 |

- 押し続けると1フレームごとに ELEV_STEP(1度)ずつ変化する。
- 初期角度は 30 度(ELEV_DEFAULT)、初期形状は立方体。
- 立体はY軸まわりに自動回転する(YAW_STEP=2度/フレーム)。
- 左上の `EL xx` が見下ろし角、左下が現在の形状名。
